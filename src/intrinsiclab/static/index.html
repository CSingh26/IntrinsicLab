Know exactly what entered the model

Import annual statements
CSV columns: fiscal_year,currency,revenue,ebit,da,capex,nwc. Consecutive annual periods; amounts in millions; CapEx as a positive outflow. Importing normalizes evidence; applying the latest row explicitly updates the model base.
Financial methodology
FCFF = EBIT − cash taxes + D&A − CapEx − Δoperating NWC. Losses do not create an immediate tax cash inflow. Cash flows are discounted at year end.
Gordon terminal FCFF = stable NOPAT × (1 − growth / ROIC). Growth therefore consumes cash through reinvestment. WACC must exceed stable growth. Exit terminal value = final-year EBITDA × selected multiple.
Equity value = enterprise value − debt − preferred equity − noncontrolling interests + nonoperating cash. Divide by diluted shares for the per-share residual.
A sensitivity range is not a confidence interval. Banks, distressed businesses, cyclicals and tax-loss dynamics require richer models. Currency, fiscal definitions and cash classifications must be consistent.
Reference: Damodaran on terminal value.
